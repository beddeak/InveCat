# InveCat

모두가 인벤토리를 공유하고 시간이 지날수록 슬롯이 줄어듭니다.

[다운로드](https://github.com/beddeak/InveCat/releases/latest)

## 설치 및 설정

Paper 26.3 · Java 25. 새 서버는 서버팩 ZIP을 빈 폴더에 풀고 Windows에서 `start.bat`을 실행하세요. 첫 실행 후 생성된 `eula.txt`를 읽고 동의하면 값을 변경한 뒤 다시 실행하세요. 기존 서버는 정지 후 `InveCat-1.0.0.jar`을 `plugins/`에 넣고 다시 시작하세요.

첫 실행 후 `plugins/InveCat/config.yml`을 편집하세요. 서버를 정상 종료하고 편집한 뒤 다시 시작하면 새 설정을 읽습니다. [기본 설정과 항목별 설명](src/main/resources/config.yml)

## 명령어

`/invecat` (별칭 `/인벤캣`, `/ic`). `status`, `credits`, `help` 외에는 `invecat.admin` 권한(기본 OP)이 필요합니다.

| 명령어 | 설명 |
| --- | --- |
| `start` (시작) | 게임 시작. 참가자 인벤토리를 비우고 체력·배고픔을 채운 뒤 시작합니다. 클리어 후에도 바로 새로 시작할 수 있습니다 |
| `stop` (종료) | 게임 종료. 사라진 칸이 돌아오고, 각자 지금 인벤토리를 그대로 가집니다(이후엔 공유 안 함) |
| `pause` / `resume` (일시정지 / 재개) | 타이머만 멈춤 / 다시 진행. 멈춘 동안에도 인벤토리 공유는 계속됩니다 |
| `interval <시간>` (주기) | 칸이 사라지는 주기 변경(config에 저장). **숫자만 쓰면 분**: `interval 10` = 10분, `interval 30s` = 30초 |
| `time <시간>` (시간) | 다음 칸이 사라질 때까지 남은 시간을 직접 지정(숫자만 쓰면 초) |
| `add <시간>` (연장) | 남은 시간 늘리기. `add -30`이면 줄이기(숫자만 쓰면 초) |
| `lock [개수]` (잠금) | 지금 바로 칸 없애기(기본 1칸). 타이머는 그대로 |
| `unlock [개수\|all]` (해제) | 가장 최근에 사라진 칸부터 되돌리기 |
| `status` (상태) | 상태, 남은 칸, 다음 칸, 진행 시간, 사라진 칸 목록, 공유 중인 사람 |
| `credits` (크레딧) | 관리자: 모두에게 크레딧 다시 재생 · 일반: 내 채팅에 기록 표시 |
| `reload` | config.yml 다시 읽기 |

시간은 `30s`, `5m`, `1m30s`, `1h`, `1분30초`처럼 쓸 수 있습니다.
