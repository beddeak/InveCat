# InveCat — 공유 인벤토리, 한 칸씩 사라지는 인벤토리

[설치용 JAR 다운로드 · GitHub Releases](https://github.com/beddeak/InveCat/releases/latest)


Paper 26.3(build 246)용 플러그인입니다. **모든 플레이어가 인벤토리 하나를 같이 쓰고, 정해진 시간(기본 10분)마다 인벤토리가 한 칸씩 사라집니다.**
엔더 드래곤을 잡으면 클리어이고, 클리어하면 크레딧이 나옵니다. plugin by beddeak(침댁)

## 규칙

- **인벤토리 공유**: 한 사람이 블록을 캐면 모두의 인벤토리에 들어가고, 한 사람이 먹으면 모두의 음식이 줄어듭니다.
  핫바·인벤토리 36칸, 갑옷 4칸, 왼손까지 전부 공유합니다. 경험치·체력·배고픔·엔더 상자는 각자입니다.
- **한 칸씩 사라짐**: 주기마다 한 칸이 무작위로 막힙니다(빨간 금지 표시 "사라진 칸"). 막힌 칸은 옮기거나 버리거나 놓을 수 없습니다.
  인벤토리·핫바뿐 아니라 **갑옷 4칸과 왼손도 사라집니다.** 갑옷 칸이 막히면 그 부위는 더 이상 입을 수 없습니다.
- **핫바 1번은 끝까지 남음**: 사라지는 칸은 핫바 1번을 뺀 40칸이고, 40칸이 다 막히면 핫바 1번 한 칸으로 드래곤을 잡아야 합니다.
- **다음에 사라질 칸 예고**: 보스바에 "다음: 핫바 3번"처럼 미리 보여 줍니다. 1분 전 채팅 경고, 5초 전부터 화면 카운트다운이 뜹니다.
- **사라지는 칸에 있던 아이템**: 기본은 다른 빈 칸으로 옮기고(입고 있던 갑옷은 벗겨져서 인벤토리로), 빈 칸이 없으면 참가자 중 한 명의 발밑에 떨어집니다(`locked-item`으로 변경).
- **클리어**: 엔더 드래곤 처치. 화면에 클리어 → 마지막 일격 → 기록 → 남은 칸 → 함께한 사람 → **plugin by beddeak(침댁)** 순서로 크레딧이 나오고 채팅에도 남습니다.
  보스바에도 기록과 크레딧이 계속 표시됩니다. `/invecat credits`로 다시 볼 수 있습니다.

칸 이름은 핫바가 1~9번, 그 위 인벤토리는 위에서부터 1줄·2줄·3줄(3줄이 핫바 바로 윗줄), 그리고 투구·상의·바지·신발·왼손입니다.

## 진행 중 생기는 일

- **누가 죽으면**: 공유 인벤토리 전체가 그 사람이 죽은 자리에 한 번 떨어지고, 모두의 인벤토리가 비워집니다(채팅에 좌표 표시).
  `keepInventory`가 켜져 있으면 아무것도 떨어지지 않습니다. 리스폰하면 지금 공유 인벤토리를 받습니다.
- **나갔다 들어오면**: 나갈 때 들고 있던 변경까지 반영되고, 다시 들어오면 그때의 공유 인벤토리를 받습니다.
- **게임 중에 새로 들어온 사람**: 서바이벌·모험 모드면 바로 공유에 참가합니다.
- **관전자·크리에이티브**: 공유하지 않습니다(촬영자, 관리자용). 참가자가 크리에이티브로 바꾸면 그 사람 인벤토리는 비워지고,
  다시 서바이벌로 오면 공유 인벤토리를 받습니다. 크리에이티브 아이템이 공유 인벤토리로 섞이지 않습니다.
- **참가자가 아무도 없으면**: 타이머와 진행 시간이 멈춥니다.
- **서버를 껐다 켜면**: 공유 인벤토리·사라진 칸·남은 시간·기록을 `plugins/InveCat/data.yml`에 저장해 두고 **일시정지 상태로** 돌아옵니다.
  모두 들어오면 `/invecat resume`. (1분마다 자동 저장도 합니다.)
- **두 사람이 같은 틱에 같은 칸을 건드리면**: 같은 아이템 개수 변화는 합칩니다(둘이 동시에 캔 블록 둘 다 들어감).
  같은 도구를 동시에 쓴 경우는 하나로 처리해서 복사되지 않습니다. 겹쳐서 넘친 아이템은 빈 칸으로 가거나 그 사람 발밑에 떨어집니다.

## 명령어

`/invecat` (별칭 `/인벤캣`, `/ic`). `status`, `credits`, `help` 외에는 `invecat.admin` 권한(기본 OP)이 필요합니다.

| 명령어 | 설명 |
| --- | --- |
| `start` (시작) | 게임 시작. 참가자 인벤토리를 비우고 체력·배고픔을 채운 뒤 시작합니다. 클리어 후에도 바로 새로 시작할 수 있습니다 |
| `stop` (종료) | 게임 종료. 사라진 칸이 돌아오고, 각자 지금 인벤토리를 그대로 가집니다(이후엔 공유 안 함) |
| `pause` / `resume` (일시정지 / 재개) | 타이머만 멈춤 / 다시 진행. 멈춘 동안에도 인벤토리 공유는 계속됩니다 |
| `interval <시간>` (주기) | 칸이 사라지는 주기 변경(config에 저장). **숫자만 쓰면 분**: `interval 10` = 10분, `interval 30s` = 30초 |
| `time <시간>` (시간) | 다음 칸이 사라질 때까지 남은 시간을 직접 지정(숫자만 쓰면 초) |
| `add <시간>` (연장) | 남은 시간 늘리기. `add -30`이면 줄이기(숫자만 쓰면 초) |
| `lock [개수]` (잠금) | 지금 바로 칸 없애기(기본 1칸). 타이머는 그대로 |
| `unlock [개수\|all]` (해제) | 가장 최근에 사라진 칸부터 되돌리기 |
| `status` (상태) | 상태, 남은 칸, 다음 칸, 진행 시간, 사라진 칸 목록, 공유 중인 사람 |
| `credits` (크레딧) | 관리자: 모두에게 크레딧 다시 재생 · 일반: 내 채팅에 기록 표시 |
| `reload` | config.yml 다시 읽기 |

시간은 `30s`, `5m`, `1m30s`, `1h`, `1분30초`처럼 쓸 수 있습니다.

## 설정 (`plugins/InveCat/config.yml`)

```yaml
lock-interval-seconds: 600   # 한 칸이 사라지는 주기(5~86400초). /invecat interval 로도 변경
countdown-seconds: 5         # 사라지기 직전 화면 카운트다운, 0이면 끔
lock-order: random           # random = 40칸 무작위, hotbar-last = 위쪽 27칸·갑옷·왼손을 다 없앤 뒤 핫바 2~9번
locked-item: move            # move = 빈 칸으로(없으면 바닥), drop = 바닥에, delete = 같이 사라짐
show-next-slot: true         # 다음에 사라질 칸 미리 알려 주기
bossbar: true
game-modes: [SURVIVAL, ADVENTURE]   # 이 모드인 사람끼리 공유
```

## 빌드

Java 25와 Gradle 래퍼(9.6.0)를 씁니다. 의존성이 캐시돼 있으면 오프라인으로 됩니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Offline
```

결과물: `build/libs/InveCat-1.0.0.jar`

## 서버 실행

`server/`에 Paper 26.3 build 246 서버가 들어 있습니다(맵은 첫 실행 때 새로 만들어짐). `start-server.bat`을 더블클릭하면
최신 빌드 jar를 `server/plugins/`에 복사한 뒤 서버를 켭니다. 끌 때는 콘솔에 `stop`을 입력합니다.

- 화이트리스트 꺼짐, 정품 인증(online-mode) 켜짐, 포트 25565, 서바이벌, 난이도 보통, 스폰 보호 0
- 처음 접속한 뒤 콘솔에서 `op <내 닉네임>`을 해야 `/invecat` 관리 명령을 쓸 수 있습니다.
- 외부 친구가 들어오려면 공유기에서 TCP 25565 포트포워딩이 필요합니다.
- 촬영자는 관전자 모드로 두면 공유에서 빠집니다.
- 맵을 새로 만들려면 서버를 끈 상태에서 `server/world` 폴더를 지웁니다.

## 크레딧에 대해

클리어 크레딧은 플러그인이 화면 타이틀·채팅·보스바로 직접 보여 줍니다. 엔드 포탈로 나갈 때 나오는 바닐라 엔딩(엔드 포엠·제작진 목록)은
클라이언트 리소스팩에 들어 있는 글이라 플러그인으로는 바꿀 수 없습니다(리소스팩을 따로 만들어 배포해야 함).

## 검증 상태

- 단위 테스트 28개(핫바 1번 고정, 갑옷·왼손 잠금 포함): 공유 칸 합치기(동시 획득·사용, 넘침, 같은 도구 동시 사용 시 복사 방지, 버리기·바꿔 끼우기 우선),
  빈 칸 채우기, 칸 잠금·해제 순서, hotbar-last 순서, 저장 복원, 타이머·시간 파싱.
- Paper 26.3-246 헤드리스 서버(접속자 없음)에서 확인: 플러그인 로드, 콘솔 명령 전체(start·lock·unlock·time·add·pause·resume·interval·credits·stop·오류 입력),
  서버 재시작 후 일시정지 상태로 복원, 소환한 엔더 드래곤 처치 시 클리어 판정과 크레딧 출력.
- **실제 플레이어 접속으로는 아직 확인하지 않았습니다.** 인벤토리 동기화, 사라진 칸 보호(클릭·드래그·버리기·설치·손 바꾸기·휠 클릭·우클릭으로 갑옷 입기),
  사망 시 드롭, 보스바·타이틀 표시는 촬영 전에 2명 이상 접속해서 `interval 30s`로 짧게 돌려 보는 것을 권장합니다.
